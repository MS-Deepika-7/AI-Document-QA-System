# AI-Based Document Question Answering System

## Project Description
This project answers questions based on information found in an uploaded document.

## Technologies Used
- Python
- Streamlit
- PyPDF
- Python-docx

## Features
- Upload a document.
- Extract text from the document.
- Create a Knowledge Base.
- Ask questions about the document.
- Display answers based on the Knowledge Base.
- Evaluate answers using test questions.

## How to Run
1. Install the required packages:
   python -m pip install -r requirements.txt
2. Run the application:
   python -m streamlit run app.py
